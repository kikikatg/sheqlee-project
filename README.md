# Sheqlee – Freelancing Platform

## Overview

Sheqlee is a full-stack freelancing platform designed to connect clients and freelancers in a modern and user-friendly environment. The platform allows users to create accounts, post jobs, submit proposals, communicate, and manage freelance work efficiently.

This project was developed as part of practical full-stack software engineering learning and focuses on scalable web application development using modern technologies.

---

## Features

* User Authentication and Authorization
* Freelancer and Client Profiles
* Job Posting and Management
* Proposal/Bidding System
* Real-time Messaging Interface
* Responsive Modern UI
* Dashboard for Users
* MongoDB Database Integration
* REST API Integration

## System Architecture

The application follows a full-stack MERN-style architecture:

* React frontend handles the user interface and client-side interactions.
* Express.js and Node.js provide RESTful APIs and backend logic.
* MongoDB stores user accounts, jobs, and platform data.
* Authentication is used to secure user access and manage sessions.

---

## Project Goals

The main goal of Sheqlee is to create a digital freelancing ecosystem where users can:

* find freelance opportunities,
* connect with professionals,
* collaborate efficiently,
* and manage freelance services online.

## Installation

### Clone the repository

```bash
git clone https://github.com/kikikatg/sheqlee-project.git
```

### Navigate into the project directory

```bash
cd sheqlee-project
```

### Install dependencies

Frontend:

```bash
npm install
```

Backend:

```bash
npm install
```

### Start the development server

Frontend:

```bash
npm run dev
```

Backend:

```bash
npm start
```
